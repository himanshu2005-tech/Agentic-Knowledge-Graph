# Triplet Extraction Metrics

This folder contains metrics evaluating the 70B model's ability to accurately extract Knowledge Graph triplets.

- **extraction_results.csv**: The raw Precision, Recall, and F1 scores for each query.
- **extraction_f1_chart.png**: A histogram showing the distribution of the non-zero F1 scores.

**Key Metric**: Macro-Averaged F1 Score. This proves the system does not hallucinate graph relationships.
