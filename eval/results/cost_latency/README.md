# Cost & Latency Metrics

This folder compares the performance overhead of different configurations.

- **cost_latency_results.csv**: Mean, median, and P95 wall-clock latency (in seconds) for Dual-Model, 70B-only, and 3B-only.
- **cost_latency_chart.png**: Visual bar chart of latency times.

**Key Metric**: Dual-Model Latency vs 3B-only latency. Proves the efficiency of the RAG architecture.
